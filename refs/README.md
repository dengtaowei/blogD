# 参考资料（不随站点部署）

本目录存放学习用原文（如芯片 Datasheet），**只进 Git 仓库**，不放入 `docs/public/`。

VitePress 构建只会把 `docs/public/` 拷进 `docs/.vitepress/dist/`，再 rsync 到 VPS；因此这里的 PDF **不会**出现在 https://blog.xvfex.com.cn 。

在线阅读 / 下载请用 GitHub，例如：

- [WM8960 Datasheet](https://github.com/dengtaowei/blogD/blob/main/refs/datasheets/WM8960.pdf)
- [AW8010A Datasheet](https://github.com/dengtaowei/blogD/blob/main/refs/datasheets/AW8010A.pdf)（Vela 板喇叭功放 AW8010AFCR）
- [MSM261D4030H1CPM Datasheet](https://github.com/dengtaowei/blogD/blob/main/refs/datasheets/MSM261D4030H1CPM_Datasheet.pdf)（Vela 板载 PDM 硅麦）

版权归原厂商；仓库内副本仅供对照阅读。
