# 灯数据线贴着 DP 时，键盘为何唤不醒休眠的电脑

> **环境**：USB 2.0 高速 Device，枚举为 HID 键盘；键盘板上还有一颗 hub。主机是 Windows。控制器是 DWC 类 USB 设备控制器（UDC）  
> **关联**：[USB HID 键盘 Remote Wakeup](/analysis/kernel/debug/usb/hid-remote-wakeup)  
> **状态**：K 停在板上的 hub；这颗芯片的静噪约在 126～131 mV。灯的电流没有把内核电压或 USB 供电拉低到唤不醒

## 1. 现象

带背光的 USB 键盘，电脑休眠后按键唤不醒。灯的数据线一断开，同一套软件就可以唤醒电脑。同一块板上对调芯片，唤不醒跟着其中一颗走；这颗芯片重新焊接之后仍然唤不醒。

设备唤醒主机时，总线上驱动的是 K（D+ 低、D− 高）。失败时这段 K 到了键盘板上的 hub 就停住，没有继续到电脑。

---

## 2. 结论先行

静噪是高速接收的电压门槛：DP−DM 小于它，接收端把总线当成没有活动。这个门槛写在 PHY 高速静噪寄存器的一个字节里，高 4 位是正常接收的档位，数值越大越不灵敏。

| 问题 | 答案 |
|------|------|
| 电脑为什么唤不醒 | 键盘打出的 K 到了板上的 hub 就停住，没有继续传到主机 |
| 为什么和灯有关 | 约 5 V 的灯数据线贴着 DP，边到边 0.18 mm，这一段没有地铜皮。数据脚翻转时会唤不醒；灯改独立供电，或灯不亮只翻转数据脚，仍然唤不醒 |
| 为什么换一颗芯片就不一样 | 静噪高 4 位写成同一档，实际门槛和耦合进来的差分仍可能不同 |
| 这颗芯片的分界 | 高 4 位 `9`（约 126 mV）仍唤不醒，`A`（约 131 mV）不再出现。原版 `0x47`（高 4 位 `4`）约 95 mV |
| 把贴近 DP 的灯数据线绕开 | 贴着走时大约 70% 会唤不醒。绕开后三十多次里没有再出现 |

---

## 3. 问题跟着灯的数据线走

断开数据线后可以唤醒电脑。灯改成独立供电，唤不醒仍然出现；灯不亮、只让数据脚翻转，唤不醒仍然出现。唤不醒随数据脚的翻转出现。这两项里，灯的电流没有把芯片内核电压或 USB 供电拉低到会唤不醒。

---

## 4. Hub 两侧的 resume

失败时 hub 上游已经挂起（suspend），远程唤醒（remote wakeup）开着。芯片引脚上能看到 K，这段 K 到了 hub 入口，同一时刻 USB 口和 hub 上游都没有这段 K。

芯片和 hub 之间的 DP 上能看到干扰。飞线把贴近 DP 的灯数据线绕开之后，没有再出现唤不醒。这段干扰要和静噪门槛比较。

---

## 5. 高速静噪门限

判断这段干扰算不算总线活动，用的是高速静噪。差分电压小于门槛时，接收端把总线当成没有活动。门槛在 PHY 的高速静噪寄存器里，具体地址因 SoC 而异。

| 位 | 作用 |
|----|------|
| 高 4 位 | 高速正常接收。驱动注释给出的两端：`0x0` 约 70 mV，`0x8` 约 120 mV，`0xF` 约 160 mV |
| 低 4 位 | 高速握手（chirp）用的另一档门槛，保持 `0x7` |

数值越大，要更大的差分电压才算有活动。门槛越低越灵敏，越高越不灵敏，实验里也叫接收灵敏度。USB 2.0 规定：不大于 100 mV 的差分视为没有信号，不小于 150 mV 的差分视为有信号，门槛落在这两者之间。

会唤不醒的那份固件把这一字节写成 `0x47`。高 4 位是 `4`，按上面的两端估算约 95 mV。只改固件写入该字节的常数，并重算校验。在同一颗会唤不醒的芯片上，高 4 位 `8`（约 120 mV）和 `9`（约 126 mV）仍然唤不醒，`A`（约 131 mV）和 `B`（约 137 mV）不再出现。干扰差分电压落在大约 126 mV 和 131 mV 之间。`C` 到 `F` 尚未测量，整字节列在附录 A。

运行中写入这个寄存器可以读回。USB 重新初始化会按固件里的这个常数再写一次，所以改门槛要改固件里的这个字节。

---

## 6. DP 和灯数据线的间距

约 126 mV 和 131 mV 之间的这档耦合，来自下面这段走线。这一段没有地铜皮。DP 线宽 0.2 mm，和灯数据线平行，边到边 0.18 mm。灯数据线约 5 V，以这个间距贴着 DP，和 DM 的间距更大。静噪比较的是 DP−DM。灯数据线只贴着 DP，耦合进来的电压就落在这个差分上。

高速线之间常用的 3W，是中心距至少 3 倍线宽，边到边至少 2 倍线宽。线宽 0.2 mm 时，边到边至少 0.4 mm。差分对与旁边其他信号的边到边间距，常见取 3 倍线宽（0.6 mm），留更多余量时取 5 倍（1.0 mm）。这些倍数按线下面有完整地平面来估算。0.18 mm 小于这些间距，大约只有一条线的宽度。

---

## 7. 小结

- K 停在板上的 hub：芯片脚和 hub 入口有，hub 上游和 USB 口没有。
- 唤不醒随数据脚翻转出现。灯独立供电，或灯不亮只翻转数据脚，仍然唤不醒。灯的电流没有把内核电压或 USB 供电拉低到会唤不醒。
- 这颗芯片上，静噪高 4 位 `9`（约 126 mV）仍唤不醒，`A`（约 131 mV）不再出现。原版约 95 mV（`0x47`）。
- DP 线宽 0.2 mm，与 5 V 灯数据线边到边 0.18 mm，这一段没有地铜皮。贴着走大约 70% 会唤不醒；绕开后三十多次没有再出现。
